We used Replit to develop, run and publish the StockLink prototype. The publicly accessible deployment includes Overview, Orders, Inventory, Deliveries and Activity views.

The prototype uses synthetic demonstration data stored locally in the browser. It demonstrates order-linked inventory forecasts, stock-risk explanations and human-reviewed decisions. No live AI model, supplier messaging or automatic purchasing is integrated into the application. AI assistance used during development is disclosed separately in the technical tools declaration.

## What the evidence establishes

The public Replit deployment is the selected usage evidence, corresponding to orientation slide 29. The project link is provided as supporting context; access to its editor or internal history may depend on Replit account permissions. A reviewer can open the live URL without an application login and inspect the functional views.

This statement does not claim a particular credit balance, amount spent or workshop attendance. No credit-usage screenshot is required for the selected live-URL evidence unless the organizers request additional verification.

## RunPod declaration

The team confirms that RunPod was not used. The current StockLink demo performs no GPU training, fine-tuning or model inference. There is no RunPod Pod ID, GPU runtime or endpoint to report. Orientation slide 29 requires RunPod for GPU work; no GPU-work evidence is claimed for this browser-only prototype.
